# /update-readme-and-readme-cn

Use this workflow when working on **update-readme-and-readme-cn** in `InkAI-`.

## Goal

Keeps both the English and Chinese README files up to date with project changes, new features, architecture evolution, feedback channels, and issue fixes.

## Common Files

- `README.md`
- `README_CN.md`

## Suggested Sequence

1. Understand the current state and failure mode before editing.
2. Make the smallest coherent change that satisfies the workflow goal.
3. Run the most relevant verification for touched files.
4. Summarize what changed and what still needs review.

## Typical Commit Signals

- Edit README.md to add or update project information, architecture diagrams, issue fix cases, or feedback channels.
- Edit README_CN.md to mirror the changes in Chinese.
- Optionally update related documentation or requirements if needed.
- Commit both README.md and README_CN.md together.

## Notes

- Treat this as a scaffold, not a hard-coded script.
- Update the command if the workflow evolves materially.
